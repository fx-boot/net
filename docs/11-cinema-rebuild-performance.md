# LANCHUAN × 東浩：展映系统与性能重构

2026-10-22。预览：<http://127.0.0.1:5173/>。本记录替代第 10 阶段中有关持续环境流光、非对称六片网格和逐卡滚动 Observer 的描述。

## 改动

- 固定的 `CardTrigger` 承接鼠标、焦点与点击。所有缩放、倾角、位移、入场和阴影均在 `CardVisual` 中；视觉层及后代统一 `pointer-events: none`。卡片外层不再包在变形入场节点中。轮播切换期间暂停卡片指针命中，避免移动中的画幅截获悬停。
- `cinemaFrames.ts` 将帧拆为 measure / write 两阶段；滚动场景先收集几何信息，再统一写样式。指针事件仅记录位置，感应外壳的几何信息按进入、滚动和尺寸变化失效后读取；插值根据 delta time 归一。滚动场景共用 IntersectionObserver 与 ResizeObserver，退出/卸载取消订阅。
- Lenis 保留一个手动 RAF，使用 `lerp: .085` 的时间归一阻尼；移除会覆盖 lerp 的 duration/easing 双配置。页面隐藏取消驱动，恢复后重启。
- 环境光改为静态径向渐变；移除持续漂移、全屏混合模式、模糊影子、模糊入场副本和局部动态噪点。滚动仅推动低透明度胶片网格、画幅、字幕与序号。滚动/倾角激活期间设置 will-change，停下或退出后移除。
- 作品默认为居中巨幕：主片占舞台宽度 72%，桌面统一 2.39:1；侧片 opacity .25 / scale .88。手机为 84% 主画幅、统一 16:9。支持前后循环、方向键、横向指针拖动与触摸横滑逻辑，含计数标尺与四语提示。
- 轮播按逻辑位置回收相邻窗口，最多挂载 5 个画幅；四片分类只挂载 3 个，语言变化保留当前影片。预览始终只为当前 hover/focus 影片创建。
- Archive 为均等网格，每次加载 6 部；加载后焦点交给新批次首部，避免最后一个加载按钮消失后焦点丢失。新增四语文案集中于 `i18n/cinema.ts`。
- 片库工厂输出 12 条演示记录，保留原六部 ID 和全部媒体。新增六部概念条目复用已有授权素材，并标记 `sourceProjectId`、`isPlaceholder: true`。扩充至 20/50 条只需调整 `createDemoCatalog()` 的数量或提供实际多语言项目记录，组件不依赖六片上限。
- 生产模型使用 `ContentRecord`，允许真实条目标记 `isPlaceholder: false`；演示工厂仍明确输出 true。实际 API 可直接提供 `Project[]` 或 `LocalizedCatalog`，不必把真实影片伪装成演示条目。

### 10 秒连续滚轮

1440×900，10.024 秒内发送 137 次滚动输入，持续跨章节滚动并在页尾反向。采样快照记录 584 个滚动帧回调：平均 16.6659ms，P95 16.8ms，最大 16.9ms；大于 34ms 的回调为 0。RAF 驱动数量 1，已标记场景的 read-after-write 计数 0。

以上是本机约 60Hz 环境的 RAF 回调间隔，不能当作 GPU 呈现帧率、浏览器内部完整 Layout trace，或所有设备稳定 120 FPS 的保证。120Hz 的阻尼按 delta time 归一，但未进行 120Hz 真机测试。横滑共用 Pointer Events，已用真实指针拖动验证；手机检查为视口测试，未冒称触摸真机验收。系统 reduced-motion 的 JS/CSS 分支保留，当前浏览器工具不提供系统媒体偏好模拟。
