# 暗房暖色与影像调色 — 2026-10-19

保留上一版 12 列画册布局、媒体文件、四语字典、播放状态管理和弹窗无障碍逻辑。本轮改动集中于色彩和视觉反馈。

## 实现

- tokens.css 改用用户指定的八个暖色语义令牌；移除旧蓝黑、蓝灰、冰蓝变量。global.css、motion.css、uiverse.css 统一引用新令牌，弹窗和弹窗顶部使用暖炭层。
- 作品封面和悬停预览共用默认胶片滤镜及内暗角；hover、键盘 focus-visible、预览就绪时恢复通透色彩并 scale(1.015)，滤镜和缩放以 0.7s 指定曲线过渡。遮罩不拦截指针，原有预览透明度过渡保留。完整影片文件不做破坏性调色。
- Hero 叠加暖黑径向与纵向渐变，底部自然衔接主背景，标题用轻微暖银光泽；强制颜色模式回退为可读纯色文字。
- About 背景在章节上下边缘渐变衔接主背景；肖像应用 grayscale(100%) contrast(1.12) sepia(0.08)。四语独白首句用黄铜金，原文内容不变。
- 选中分类采用 5px 朱砂圆点；作品说明行和奖项行交互时出现 5% 暖金底色，次级文字提亮。桂冠、链接 hover 和键盘焦点使用黄铜金。
- 现有 prefers-reduced-motion 禁用过渡和动画的规则继续生效；没有新增滚动监听或动画循环。

## 验证

- `npm run build`：TypeScript 与 Vite 构建通过。
- `npm run lint`：通过。
- `npm run verify:assets`：11 份上游源码、34 份资源哈希、四语字典和 24 条本地化作品通过；原始调研文档未改动。
- 1440 × 900 浏览器实测：背景 rgb(10,9,8)，选中点 rgb(200,75,49)、5px，12 列布局保留。
- 实际 Tab 聚焦作品后：预览播放、封面与视频滤镜都为 contrast(1.04) saturate(1.02) brightness(1)，缩放 1.015，说明行底色 rgba(197,160,89,0.05)。默认状态滤镜与暗角也已读取核对。
- 奖项鼠标激活及键盘聚焦可显示暖金反馈与桂冠。四语切换的首句识别正确，无横向溢出。刷新后应用控制台无 error/warn。
- 此轮未重跑所有历史弹窗与媒体异常场景；这些逻辑没有改动。
