# Changelog

## 0.1.0 — 2026-10-23

First versioned release of the existing LANCHUAN × DONG HAO demonstration website.

- Four locales, local typefaces, 12-film expandable catalog, cinema carousel and Archive.
- Single-frame scheduler, static pointer triggers, accessible film dialogs and reduced-motion fallbacks.
- Living 12fps quarter-resolution grain, bounded anamorphic spill, source-frame scrubbing and spring transport ruler.
- Keyboard/pointer/touch color-study comparison; default-off, consent-only synthesized atmosphere.
- Licensed source metadata, 24 extracted keyframes, build and focused regression scripts.
- Cache/credential exclusions, byte-preserving provenance rules, and curated visual acceptance records.

The earlier dated documents record development milestones. Git history begins with this import; no earlier commits, authors or timestamps have been fabricated. This release is a runnable demonstration, not a production deployment or a claim of verified directing/VFX credits.
